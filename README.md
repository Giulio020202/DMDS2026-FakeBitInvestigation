# DMDS2026 — FakeBitInvestigation

Repo del gruppo `fakebitinvestigation` per la challenge **Capture the Mark 2026** (Multimedia Data Security, Università di Trento).

La versione consegnata è la **2.0 ibrida (DCT + wavelet)**, in [`embedding/v2.0_ibrida/`](embedding/v2.0_ibrida/):

- istruzioni per eseguire embedding, detection, attacchi, script di gara, ROC e demo: [`README.md`](embedding/v2.0_ibrida/README.md);
- spiegazione dell'algoritmo: [`spiegazione_embedding.md`](embedding/v2.0_ibrida/spiegazione_embedding.md).

Altre cartelle:
- `embedding/sample-images/`: le 101 immagini di prova;
- `embedding/fakebitinvestigation.npy`: il nostro watermark;
- `embedding/esperimenti/`: gli script degli esperimenti da cui vengono i numeri della spiegazione.
